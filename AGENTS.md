# Project Guidelines

## Critical Note
This workspace uses Next.js 16 + React 19. Do not assume legacy Next.js behavior.
Before implementing non-trivial framework changes, review relevant docs in node_modules/next/dist/docs/ and check deprecations.

## Build and Validation
- Install deps: npm install
- Dev server: npm run dev
- Production build: npm run build
- Start production server: npm run start
- Lint: npm run lint
- Tests: no test runner is configured yet. Do not invent test commands.

## Architecture
- app/layout.tsx defines root HTML/body structure, global fonts, and metadata.
- app/page.tsx is the default home route.
- app/globals.css holds Tailwind import and global stylesheet imports.
- components/gridTable/gridTable.tsx is a custom grid-related component based on react-grid-layout.
- public/ contains static assets.

## Conventions
- Use TypeScript with strict mode and preserve existing typing style.
- Prefer the @/* import alias for workspace-root imports.
- Follow Next.js App Router conventions under app/.
- Respect ESLint config in eslint.config.mjs (next/core-web-vitals + next/typescript).
- Keep edits minimal and scoped; avoid broad refactors unless requested.

## Project Pitfalls
- After renaming routes in App Router, clear .next before a production build to avoid stale type artifacts.
- Do not use browser-only APIs (for example localStorage) in server-rendered paths without guards.
- next-env.d.ts is generated by Next.js; do not edit manually.
